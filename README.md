
# ChairFill AI 🚀

AI SaaS designed to help dental clinics recover cancelled appointments and fill empty chairs automatically.

## About

ChairFill AI helps dental clinics reduce losses caused by cancelled appointments and no-shows.

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- Supabase
- Artificial Intelligence

## Getting Started

Install dependencies:

npm install

Run the project:

npm run dev
